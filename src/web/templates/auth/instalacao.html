Criar o administrador

Primeiro acesso: este será o administrador do sistema, com controle total. Você poderá cadastrar outros usuários depois.

3 a 32 caracteres: letras minúsculas sem acento, números, ponto, hífen ou sublinhado.
  • Pelo menos 8 caracteres
  • 3 tipos entre minúsculas, MAIÚSCULAS, números e símbolos (ou 16+ caracteres)
  • Sem o nome de usuário

Guarde esta senha com cuidado: o sistema só guarda uma "impressão digital" dela e não consegue mostrá-la de novo. Se perder, a recuperação exige estar neste computador.
